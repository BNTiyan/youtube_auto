GitHub Page Video Intake

Turn a topic and text into a video request

Share this page with collaborators. They can submit a topic, paste source text or notes, and GitHub Actions will turn the request into a video generation job through a structured GitHub issue.

Videos are generated with local Ollama after a repository collaborator approves the request with the video-request label.

How it works

  1. Fill in the topic and the text you want converted into a video.
  2. The button opens a prefilled GitHub issue labeled video-request.
  3. Submit the issue on GitHub.
  4. A workflow picks it up, generates the video and Short, and comments back on the issue.

The generated content should be original. Use this page to submit ideas or source material you have permission to use.
