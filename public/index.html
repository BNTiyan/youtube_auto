Private Repo Friendly

Submit a topic and text for video creation

This page sends your request to a secure backend on Vercel, which triggers the private GitHub workflow. Use it to submit a topic, source text, and optional notes without exposing the repository publicly.

What happens next

  1. Your request is posted to a secure Vercel API endpoint.
  2. The endpoint triggers the private GitHub Actions workflow.
  3. The workflow generates a regular video and a Short from your topic and text.
  4. You can monitor progress in the GitHub Actions workflow page.

Keep the submitted text original or permitted for reuse. The system rewrites it into an educational video package.
